# AZUR LANE: JANUS MOD / 碧蓝航线雅努斯模组

让来自《碧蓝航线》的 J 级驱逐舰雅努斯加入尖塔。她会克服胆怯，以独特的“日记本”牌堆记录经历、珍藏回忆，并在关键时刻从中汲取力量。

本模组需要前置模组 **STS2-RitsuLib 0.6.2 或更高版本**。

![Mod Content](https://raw.githubusercontent.com/FaFa-magic/JanusSpire2/main/workshop/images/janus_workshop_content.png)

## MOD CONTENT / 模组内容

- 1 个全新可玩角色：**雅努斯（Janus）**
- **91 + 14** 张新卡牌：91 张常规及多人卡牌，另有 14 张先古、衍生与状态牌
- **20** 个新遗物
- **3** 种新药水
- 1 位新先古之民：**伊丽莎白女王（Queen Elizabeth）**
- 1 个新事件：**小猫的卡牌游戏（Kitten's Card Game）**
- **7** 套可切换角色装束，每套均配有独立的战斗、商店与休息点 Spine 模型

## DIARY MECHANICS / 机制讲解

### DIARY / 日记本

日记本是雅努斯的专属卡牌区域。多种卡牌与关键词可以将牌写入日记本、从中触发效果，或把其中的牌作为资源消耗。围绕日记本进行记录、整理与回忆，是雅努斯构筑的核心。

### RECORD & TRANSCRIBE / 记录与誊抄

**记录（Record）**：卡牌打出后，如果没有被消耗，便会加入日记本。

**誊抄（Transcribe）**：卡牌打出后，将一张本牌的复制牌加入日记本；当它位于日记本中时，描述中的后续效果才会生效。

### RECOLLECTION / 回忆

带有**回忆（Recollection）**的牌会在日记本中等待指定条件。条件满足后，它的投影会自动出现在额外手牌区，可以直接从日记本中打出；打出后，相应条件会被重置。

### PERK / 振作

当能量不足以打出带有**振作（Perk）**的卡牌时，可以消耗日记本中等同于缺少能量数量的牌，补足费用并打出该牌。

### COLLECTION & STICKER / 珍藏与贴纸

带有**珍藏（Collection）**的牌会在战斗开始时直接加入日记本。

**贴纸（Sticker）**可以无限升级。当消耗牌堆中集齐 4 张同名、同升级等级的贴纸牌时，它们会被移除，并将一张升级后的同名贴纸加入日记本。

### INSPIRATION / 灵感

带有**灵感 X（Inspiration X）**的牌不在手牌中时，可以右键该牌并消耗日记本中的 X 张牌，将它加入手牌。

## EXTRA FEATURES / 额外功能

- 可在模组设置中切换 **7 套雅努斯装束**。
- 可在两套雅努斯专属卡框之间自由切换。
- 多人模式的指向与猜拳模型可选择“手部模型”或“腿部模型”。
- 可分别控制“伊丽莎白女王”先古之民与“小猫的卡牌游戏”事件是否出现。
- 包含专属日记本界面、额外手牌交互、角色卡图、能力图标、遗物、药水、休息点选项与主题化原版资源替换。
