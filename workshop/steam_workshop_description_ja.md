# バージョン互換性

本Modは『Slay the Spire 2』の正式版とBeta版の両方に対応しています。SteamでゲームとModのバージョンが一致しないと表示された場合は、一度サブスクライブを解除してから再度サブスクライブしてください。多くの場合、Steamワークショップの配信キャッシュが原因です。

# アズールレーン：ジェーナス キャラクターMOD

『アズールレーン』のJ級駆逐艦ジェーナスが塔に参戦します。臆病な自分を乗り越えながら、体験を記録し、思い出を秘蔵し、専用カード領域の**日記帳**から力を引き出して戦います。

本Modの導入には **STS2-RitsuLib 0.6.2以降** が必要です。

![Modコンテンツ](images/janus_workshop_content.png)

## MOD CONTENT / 収録内容

- 新しいプレイアブルキャラクター：**ジェーナス** 1人
- 新規カード **89 + 14枚**：通常・マルチプレイカード89枚、エンシェント・生成・状態カード14枚
- 新規レリック **20個**
- 新規ポーション **3種**
- 新しいエンシェント：**クイーン・エリザベス** 1人
- 新イベント：**子猫のカード遊び** 1種
- 切り替え可能な衣装 **7種**。各衣装に専用の戦闘・ショップ・休憩所用Spineモデルを収録

## DIARY MECHANICS / 日記帳システム

### 日記帳

日記帳はジェーナス専用のカード領域です。さまざまなカードやキーワードによってカードを日記帳へ加え、そこから効果を発動したり、中のカードを資源として廃棄したりできます。日記帳への記録・整理・回想が、ジェーナスのデッキ構築の中心となります。

### 記録＆転記

**記録**：プレイ後、廃棄されなかった場合、そのカードを日記帳に加えます。

**転記**：プレイ後、そのカードのコピーを日記帳に加えます。カードが日記帳にある間、説明文の後半に記された効果が有効になります。

### 回想

**回想**を持つカードが日記帳にある間、指定された条件を満たすと、その投影が追加手札に自動的に現れます。投影は日記帳からプレイでき、プレイ後に条件がリセットされます。

### 奮起

**奮起**を持つカードをプレイするためのエナジーが足りない場合、不足分と同じ枚数のカードを日記帳から廃棄してプレイできます。

### 秘蔵＆ステッカー

**秘蔵**を持つカードは、戦闘開始時に日記帳へ加えられます。

**ステッカー**は何度でもアップグレードできます。廃棄札に、カード名とアップグレード段階が同じステッカーカードが4枚そろうと、それらを取り除き、1段階アップグレードした同名ステッカーを日記帳に加えます。

### ひらめき

**ひらめきX**を持つカードが手札にない時、そのカードを右クリックし、日記帳のカードX枚を廃棄することで手札に加えられます。

![追加機能](images/janus_workshop_extras.png)

## EXTRA FEATURES / 追加機能

- Mod設定から**7種類のジェーナス衣装**を切り替え可能。
- 2種類のジェーナス専用カードフレームから選択可能。
- マルチプレイの指差し・じゃんけん表示を「手のモデル」と「脚のモデル」から選択可能。
- エンシェント「クイーン・エリザベス」とイベント「子猫のカード遊び」の出現を個別に設定可能。
- 専用の日記帳画面、追加手札との連携、カードイラスト、パワーアイコン、レリック、ポーション、休憩所の「日記を書く」選択肢、一部基本ゲーム資源のテーマ変更を収録。
